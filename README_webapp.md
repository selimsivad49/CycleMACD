# CycleMACD Web Application

日本株のMACDヒストグラム戦略バックテストを行うWebアプリケーションです。

## 機能

- **複数銘柄の一括分析**: 10銘柄を同時に分析可能
- **インタラクティブなWebUI**: ブラウザから簡単操作
- **詳細チャート表示**: 価格、MACDシグナル、累積リターンを可視化
- **パフォーマンス指標**: リターン、勝率、ドローダウン、シャープレシオを計算
- **日付範囲指定**: 任意の期間でバックテスト実行

## セットアップ

### 1. 依存パッケージのインストール

```bash
pip install -r requirements.txt
```

または手動で：

```bash
pip install flask yfinance pandas numpy matplotlib seaborn
```

### 2. アプリケーション起動

簡単起動：
```bash
python3 run_webapp.py
```

または直接起動：
```bash
python3 app.py
```

### 3. Webブラウザでアクセス

```
http://localhost:5000
```

## 使い方

1. **銘柄選択**: 分析したい銘柄にチェックを入れる
2. **期間設定**: 開始日と終了日を指定
3. **分析開始**: 「分析開始」ボタンをクリック
4. **結果確認**: 分析結果テーブルで各銘柄のパフォーマンスを確認
5. **チャート表示**: 詳細チャートボタンで個別銘柄の可視化

## 技術仕様

- **フレームワーク**: Flask (Python)
- **データソース**: Yahoo Finance (yfinance)
- **フロントエンド**: Bootstrap 5 + Vanilla JavaScript
- **チャート**: Matplotlib
- **戦略**: MACDヒストグラム・ゼロライン戦略

## API エンドポイント

- `GET /`: メインページ
- `POST /analyze`: 株式分析実行
- `GET /chart/<symbol>`: 個別銘柄チャート生成
- `GET /health`: ヘルスチェック
